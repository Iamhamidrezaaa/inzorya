# گزارش ممیزی وضعیت فعلی Inzorya  
**فقط خواندن · مبتنی بر کد واقعی · بدون پیشنهاد معماری آینده**

وضعیت کلی: **یک اپلیکیشن Next.js کامل با اسکیمای غنی، سرویس‌های دامنه‌ای واقعی، و پلتفرم AI که عملاً همیشه mock است.** معماری Agent (goal → plan → tool → observe → iterate) وجود ندارد.

## 4. BUSINESS BRAIN — FUNCTIONAL

**ورودی کاربر:** مصاحبه ساختاریافته (`BRAIN_QUESTIONS` در `src/lib/business-brain.ts`) + voice + assets.  
**ذخیره:** `BusinessAnswer` / `BrandVoice` / `BrandAsset` روی `BusinessBrain`.  
**اعتبارسنجی:** کلید سؤال از کاتالوگ؛ امتیاز `refreshBrainScore`.  
**نسخه‌برداری:** `BusinessBrainVersion` / `snapshotBrain`.  
**مصرف‌کنندگان:**
- `composeContext` → provider `business_brain` (`src/server/ai/context/engine.ts`)
- Strategist / Planner / Creator / Community از طریق context providers
- Matching قطعی عمدتاً از Brand/Knowledge/Event — **نه لزوماً تمام جواب‌های Brain**

**مسیر نمونه:**  
Interview UI → `POST /api/brain` → `BusinessAnswer` → `composeContext` → `runAITask` (mock) → پاسخ ساختگی با echoی context.

**AI interpretation جدا:** ندارد (فقط context JSON کوتاه).  
**حافظه جداگانه Brain:** نسخه‌ها + memory records عمومی AI؛ نه memory اختصاصی مصاحبه.

# INZORYA — CURRENT REALITY

### What is genuinely working
Auth، Workspace/Brand، Onboarding، Business Brain، Strategy CRUD، Calendar catalog، Deterministic matching، Opportunities persistence، Knowledge Graph admin، Inbox/Contacts، Planner/Creator/Studio **ذخیره DB**، Meta sandbox connect، i18n، شل داشبورد AI-first (ناوبری/هوم).

### What is partially working
Campaign recommendations (eligibility واقعی + generate mock)، Community assist، Decisions/Work/Pipeline، Automations editor، Meta OAuth واقعی (پشت پرچم)، Handoffs بین ماژول‌ها.

### What is only UI/schema
صفحات reserved مثل Agents، بخشی از Team/Integrations catalog، بسیاری taxonomy models، AI queue بدون worker، embeddingRef بدون vector DB.

### What is currently mocked
تمام خروجی‌های `runAITask` با پیش‌فرض `AI_FORCE_MOCK=true`، Analytics bundle، بخش زیادی از «هوش» Community/Strategist/Creator/Planner/Campaign generate، sandbox social tokens.

### What AI actually does
یک executor یک‌مرحله‌ای context را از Postgres می‌خواند، prompt را آماده می‌کند، و **MockAIProvider** JSON قطعی برمی‌گرداند؛ اجرا در `AITaskExecution` و جداول دامنه ذخیره می‌شود. **هیچ HTTP به OpenAI/Anthropic زده نمی‌شود.**

### What Agent capabilities already exist
هیچ Agent واقعی. فقط task runners و UIهای ماژولار.

### What tools an Agent can already call
از دید Agent: **هیچ tool ثبت‌شده‌ای نیست.** از دید انسان/کد: ده‌ها service/API دامنه قابل فراخوانی برنامه‌ای.

### What data an Agent can already access
(اگر به سرویس‌ها وصل شود:) Brain، Strategy، Events، Opportunities+Scores، Knowledge nodes، Plans/Generated content، Conversations، Campaigns، MemoryRecord متنی، ConnectedAccounts metadata.

### What an Agent cannot do yet
Tool selection، multi-step reasoning loop، web search، live social read/write، image gen، RAG، real LLM، background autonomous runs، NL «۳۰ روز فرصت» به‌عنوان محصول Agent.

### Strongest existing foundations
Deterministic Matching · Calendar catalog · Business Brain + Context engine · Prisma domain breadth · Task/executor scaffolding.

### Biggest architectural gaps
No agents/tools · Mock-only AI · No workers · No real publish/analytics · Knowledge not queryable as RAG/tool.

### Current system flow

```
User
→ Auth (NextAuth)
→ Workspace / Brand
→ (optional) Onboarding + Business Brain interview
→ Dashboard Home (goals / prompt → deep-link)
→ Module UI (Strategist | Planner | Matching | Calendar | …)
→ API Route Handler
→ Domain Service
→ Prisma/Postgres
→ (optional) runAITask → MockAIProvider → JSON
→ Persist domain + AITaskExecution
→ UI render
→ [STOP: no autonomous agent loop, no live LLM, no real social publish by default]
```
